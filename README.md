# 👋 Olá, eu sou Samuel Marques

### Front-end Developer | Angular | React | TypeScript

Desenvolvedor Front-end formado em Análise e Desenvolvimento de Sistemas, focado no desenvolvimento de aplicações web modernas utilizando Angular, React, TypeScript e JavaScript.
